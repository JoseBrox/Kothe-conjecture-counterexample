# A Counterexample to Köthe's Conjecture

[![Build manuscript](https://github.com/JoseBrox/Kothe-conjecture-counterexample/actions/workflows/latex.yml/badge.svg)](https://github.com/JoseBrox/Kothe-conjecture-counterexample/actions/workflows/latex.yml)

This repository contains a human-readable proof of a counterexample to Köthe's conjecture.

The main result proved in the manuscript is:

> For every countable algebraically closed field \(k\), there exists a three-generated nil nonunital \(k\)-algebra \(A\) such that \(M_2(A)\) is not nil. Consequently, there exists a unital ring containing two nil left ideals whose sum is not nil.

## Provenance and attribution

The counterexample construction is derived from the machine-checked Lean 4 proof generated by a pre-release GPT-6 Astra model in an Epoch AI LeanOpenProblems evaluation and archived in [`tadamcz/koethe`](https://github.com/tadamcz/koethe). It is **not an independent discovery** of the counterexample.

The exact formal proof source used for the reconstruction is the repository at commit [`b0527558797325e98a8e57f2197e527210290dc4`](https://github.com/tadamcz/koethe/tree/b0527558797325e98a8e57f2197e527210290dc4), in particular [`Koethe/Resolutions/Koethe.lean`](https://github.com/tadamcz/koethe/blob/b0527558797325e98a8e57f2197e527210290dc4/Koethe/Resolutions/Koethe.lean).

The manuscript reorganizes and simplifies the formal construction in standard mathematical language. See [PROVENANCE.md](PROVENANCE.md) for the exact relationship and attribution details.

## Build

A TeX Live installation with `latexmk` is sufficient:

```bash
make
```

or directly:

```bash
latexmk -pdf -file-line-error -halt-on-error -interaction=nonstopmode paper.tex
```

GitHub Actions independently compiles the manuscript on every push and pull request. On pushes to `main`, it also updates the `generated` branch with the compiled PDF.

## Review status

The original Lean theorem is machine checked. The human-readable reconstruction in this repository has been audited for internal consistency and for agreement with the formal construction, but it has not yet undergone independent journal peer review. Mathematical corrections are welcome through GitHub issues; please identify the relevant section, theorem, lemma, or displayed equation.
